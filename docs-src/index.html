Use it in your project

          

            Import one or several SVG strings. A bundler resolves package
            imports; browsers cannot load bare npm or JSR specifiers directly.
          

          
import { folder, printer } from 'gnomicon';
// Insert only trusted package SVG:
document.querySelector('.icon').innerHTML = folder;

          

            For a direct per-icon entry point, use import { svg } from
              'gnomicon/icons/folder'. Individual files remain available
            in dist/svg/; there is no combined sprite.
          

          

            Inline SVG snippets copy the icon markup; set color on
            the inserted SVG to apply currentColor. Add your own CSS or
            JavaScript animations. Grappa's initial state is static; GTK
            animations are not included.
          

          

            JSR namespace is not chosen; @your-scope shown here is
            a placeholder, not a published package.
